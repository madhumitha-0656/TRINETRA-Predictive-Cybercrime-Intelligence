# TRINETRA
### Predictive Cybercrime Cash-Out Intelligence Network

**Smart India Hackathon 2026 | Team Furious Rookie**

TRINETRA is a predictive cybercrime intelligence prototype designed to help
authorized investigators anticipate the probable geography, time window and
mode of cash-out of cyber-fraud proceeds.

Instead of stopping at:

**"Where did the money go?"**

TRINETRA asks:

**"Where is it likely to emerge next?"**

---

## Problem Statement

Cyber-fraud proceeds can rapidly move through multiple layers of mule accounts
before being withdrawn or otherwise cashed out. Investigators therefore need
forward-looking intelligence that can help prioritize intervention while the
funds are still moving.

## Our Solution

TRINETRA converts complaint-linked transaction trails into a dynamic
multi-hop money-flow graph and combines:

- Transaction graph intelligence
- Mule-account risk analysis
- Historical fraud-pattern matching
- Temporal behaviour analysis
- Geospatial cash-out intelligence
- Explainable predictive scoring

The system forecasts:

**WHERE** — probable cash-out risk zones  
**WHEN** — probable cash-out time window  
**HOW** — likely cash-out mode  
**CONFIDENCE** — explainable prediction confidence

## Digital Nakabandi

TRINETRA introduces the concept of **Digital Nakabandi** — a predictive
digital perimeter around probable cash-out zones, allowing investigators
to prioritize areas where intervention may be most valuable.

## Key Features

- Authorized prototype access
- New cyber-fraud complaint registration
- Existing case investigation
- Multi-hop transaction graph visualization
- Mule Risk Score
- Cash-out zone forecasting
- Cash-out time-window prediction
- Historical fraud-pattern comparison
- Digital Nakabandi risk map
- Explainable model insights
- Investigation feedback loop

## Prototype Workflow

Complaint → Transaction Graph → Mule Analysis → Pattern Matching →
Predictive Engine → Cash-Out Intelligence → Digital Nakabandi

## Technology Stack

**Frontend:** React, TypeScript, Vite  
**Visualization:** Interactive graph and geospatial interfaces  
**Data:** Privacy-preserving synthetic transaction dataset  
**Architecture:** Modular service-based prototype

The prototype is designed for future integration with authorized banking
and government systems through secure APIs.
